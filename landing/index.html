Todo lo que hace

Sustituye el inicio de Amazon y se maneja con el mando de siempre o desde el móvil.

Inicio sin anuncios

Tus apps en el orden que quieras, con el botón Inicio del mando llevándote siempre a Aura.

Limpieza en un minuto

Al instalarla, una bienvenida desactiva rastreo, anuncios por intereses, tráileres automáticos y sonidos.

Salvapantallas propio

Hora, fecha y clima sobre tus fondos. La pantalla no se apaga salvo que tú lo elijas.

Fondos de vídeo

Fotos de naturaleza según la hora, o vídeos de YouTube, de un enlace o subidos por ti.

Mando web

Escanea el QR y controla la TV desde el móvil o el PC: navegar, escribir, encender y apagar.

Instalar y quitar apps

Sube un APK o pega un enlace desde la web, o busca en la Appstore de Amazon.

Código de seguridad

Un PIN opcional para que nadie más pueda usar el mando web aunque vea el QR.

Control por voz

Incluye un servidor MCP para manejar la TV hablando con un asistente.

Capturas reales

Tomadas en un Fire TV Stick 4K.

Cómo instalar

Dos formas. Con el PC además se conceden los permisos que Aura necesita para la limpieza y el salvapantallas.

En el Fire TV, con Downloader

Sin cables. Necesitas la app gratuita Downloader de la Appstore.

  1. En el Fire TV: Ajustes › Mi Fire TV › Opciones de desarrollador y permite Apps de origen desconocido para Downloader.
  2. Abre Downloader y escribe el enlace directo al APK (donde publiques esta carpeta):
https://tu-dominio/downloads/Aura-latest.apk
  1. Instala, abre Aura y sigue la bienvenida.

Para que la bienvenida pueda desactivar los ajustes de Amazon hace falta, una sola vez, el paso del PC (permisos por ADB).

Desde el PC, con ADB

Activa Depuración ADB en las Opciones de desarrollador del Fire TV. Cambia la IP por la de tu tele.

adb connect 192.168.1.50:5555 adb install -r Aura-latest.apk

Permisos (una vez; se mantienen al actualizar):

adb shell pm grant com.david.aura android.permission.WRITE_SECURE_SETTINGS adb shell appops set com.david.aura WRITE_SETTINGS allow adb shell appops set com.david.aura SYSTEM_ALERT_WINDOW allow adb shell appops set com.david.aura REQUEST_INSTALL_PACKAGES allow adb shell cmd notification allow_dnd com.david.aura adb shell settings put secure enabled_accessibility_services com.david.aura/com.david.aura.HomeWatcherService adb shell settings put secure accessibility_enabled 1
